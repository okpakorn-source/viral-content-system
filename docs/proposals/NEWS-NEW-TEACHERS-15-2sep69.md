## 2) ข้อควรระวังหลัก

### 2.1 กลุ่มฮลุน 6 ใบ — ห้ามใส่หมด
ผู้สมัคร 6/15 ใบเป็นเรื่องฮลุน (#1 #2 #4 #7 #10 #12) และคลังมีครูฮลุนอยู่แล้ว 1 ใบ (dacab8b3 · ช่วยเหลือกัน · 83,265) — ใส่หมดจะมีครูฮลุน 7 ใบ ธีมทับกัน (การเดินทาง/กตัญญู/การสูญเสีย/คุณย่า) และไลก์ทุกใบ ≥ 80k = ยืนหัวแถวโผพร้อมกันภายใต้ rank-v2 (ยอดสูงนำ · หมุนแค่หัวแถว 3) → ข่าวสายเดินทาง/กตัญญู/สูญเสียมีโอกาสได้คู่ครู "ฮลุน+ฮลุน" บ่อย = นักเขียนเห็นเสียงเดียว เรื่องเดียว
**เสนอ: เลือก ≤ 2 ใบ = #1 (อาร์เมเนีย 165k — พีคอารมณ์ของกลุ่ม, ข่าวเศร้า) + #10 (พาย่า 86.7k — โทนอบอุ่น คนละหมวด คนละอารมณ์)** · สำรอง: #2 (แหลม 146k) ถ้าอยากได้ไลก์สูงกว่า แต่โทน tribute ใกล้ #1

### 2.2 พระองค์ภา (#3) — เรื่องซ้ำครูเดิมเกือบทั้งเรื่อง
ครูเดิม a0cc3dce (nostalgia · 76,317) เล่า "ทรงฝึกทหาร ตัดพระเกศา เนื้อตัวเปื้อนฝุ่น" อยู่แล้ว — ใบผู้สมัครเล่าเหตุการณ์เดียวกันจากในสนามฝึก และคลังมีครูพระองค์ภาโดยตรงอย่างน้อย 4 ใบ (a0cc3dce, 05a165bf, 8066f29a, a610dbdd) — กวาดคำ "องค์ภา" เจอที่เกี่ยวข้องรวม ~8 ใบ (เพิ่ม 1dbba688, 641d1902, 716e1a4d, 9a62e841) → ใส่เพิ่ม = ใบที่ 5 ขึ้นไป **เสนอไม่ใส่** แม้ไลก์สูง (140k)

### 2.4 ครูใหม่ต้องมีไลก์ในไฟล์ likes ไม่งั้นเป็นหมัน
กติกา rank-v2 (teacherRank.js ข้อ 3): ใบไม่มีข้อมูลไลก์ = ต่ำกว่าพื้น = ถูกหยิบได้ทางเติมเท่านั้น และไลก์อ่านจาก `data/viral-likes-real.json` (byId) **ไม่ใช่จากคอลัมน์ engagement_likes** → ขั้น import ต้องเพิ่ม byId ของครูใหม่ทุกใบ (ดูข้อ 5) · ระวังด้วยว่าถ้าวันหลังมีคนรัน `scripts/match-real-likes.mjs` ใหม่ ไฟล์จะถูกสร้างทับจาก fb-posts-parsed.json — entry ครูใหม่ (และชุด csv-2sep69 เดิม) จะหาย ต้อง merge กลับแบบเดียวกับที่ทำ 2 ก.ย. 69

### 2.5 โพสต์พระราชวงศ์ (#3, #5) — ระบบมีกติกาอะไรบ้าง
- ด่านคัดข่าวเข้า (`taxonomy.js editorialCard`): reject เฉพาะ `royalNegative` ("อ่อนไหวสถาบัน") — เนื้อหาเชิงบวกผ่านปกติ ครูก็ไม่มีด่านห้าม
- `royalWords` ใน `viralFeatures.js` เป็นแค่ฟีเจอร์นับคำเข้าโมเดลทำนายไลก์ (น้ำหนัก +0.0104 — บวกเล็กน้อย ไม่ใช่ด่าน)
- `summarizeServiceText.js` มี "โหมดทางการ" สำหรับข่าวพระราชวงศ์ (ห้ามมโนภาพ+คำลำลอง — บทเรียน GEN-177) → ความเสี่ยงจริงคือ **ราชาศัพท์/สำนวนเทิดทูนของครู royal รั่วเข้าข่าวคนธรรมดา** ผ่าน few-shot · คลังมีครูสายราชวงศ์ ~5 ใบแล้ว จึงเสนอรับเพิ่มเฉพาะ #5 (ภูฏาน — มุมมิตรภาพระหว่างประเทศ ไม่ชนใคร) และไม่รับ #3

### 2.6 เรื่องเทคนิคที่ควรรู้ก่อนเคาะ
- ตาราง `viral_examples` **ไม่มีคอลัมน์ tags** — คอลัมน์จริงที่ระบบอ่านคือ `id, title, content, writing_notes, category, engagement_likes` (+ `source_url` ตอนเขียน) · บทบาท "แท็ก" ทำผ่าน `themes` ในบัตรลักษณะ ซึ่งเตรียมให้แล้วทั้ง 15 ใบ
- `source_url` ของครูใหม่ = null (CSV มีแค่ post id — เก็บไว้ใน `_sourcePostId` ให้เจ้าของเติม URL ทีหลังได้)
- `engagement_likes` ครูเดิมเป็น 0 ทั้ง 202 ใบ — แถวเสนอใส่ค่าจริง (ช่วยเรื่อง `.order()` ที่โค้ดตะโกนเตือนว่าเป็นระเบิดเวลา) แต่ถ้าเจ้าของอยากคงแบบแผน 0 ก็ปรับได้ ไม่กระทบ rank-v2 (อ่านจากไฟล์ likes)
- คำธีมสั้นกว่า 4 ตัวอักษร (ยาย/ถ้ำ/หวย) ไม่ถูกให้คะแนนโดยตัวคัดโผ (SL.MIN_LEN=4) — บัตรทั้ง 15 เลี่ยงแล้ว
