## 1) ข้อสรุปหลัก (thesis)

1. **เพจแพ้ในหมวดที่คนรักที่สุด**: คดีความ + ศาสนา-งานบุญ + กีฬา = 20.5% ของโพสต์เพจ ไลก์กลาง **13,384 / 9,667 / 10,809** — ทุกหมวดเหนือฐานเพจ 7,752 แต่คลัง 201 ใบมีการ์ด **0 ใบ** ครูตรงหมวด **0–1 ใบ** และตัวจำแนกพาข่าวพวกนี้ตกหมวด "ดราม่าสังคม" (การ์ด 2 ใบ) — ขณะที่ข่าวดิบมีป้อนจริงสม่ำเสมอ **337/1,403 = 24%** ของ archive
2. หมวดใหม่จะ "สวย" ต้องเสียบครบ **3 ชั้นพร้อมกัน**: การ์ด (ชื่อ+600 ตัวอักษรแรกออกแบบให้บรรณารักษ์ luna ที่เป็นผู้เลือกจริง 93% อ่านขาด — Text:1294-1298) + ทางเข้า alias ใน CATEGORY_MAP (ให้ +30 พาเข้าโผ top-8) + ครูตรงหมวด (ไม่งั้นข่าวศาสนาดูดครูช่วยเหลือกัน = หมวดกลุ่มการ์ดไลก์ต่ำสุด 3,796 หรือถูกตัด few-shot ทิ้ง vf:1259)
3. ควบคู่กันต้องปิดแผลคุณภาพที่กรรมการชี้: **fidelity ~6.4 / tightness ~6.5 ต่ำสุดทั้งกระดาน** (opening ~7.3 ดีอยู่แล้ว) — ต้นตอคือใบสั่งทุกฉบับมีคำสั่งปิดเรื่อง 2 แบบขัดกัน (ctaStyle 201/201 สั่ง "อวยพรสั้น" vs VR-006 ห้ามอวยพร+ต้อง callback โดยไม่มีบรรทัดตัดสิน Text:1937) → แก้ด้วยกฎ **VR-011 ฉบับ data-only 1 ข้อ** + พักเฉพาะใบที่มีหลักฐานเสียจริง **29 ใบ**
