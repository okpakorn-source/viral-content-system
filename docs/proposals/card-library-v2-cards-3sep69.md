# บันทึกเหตุผลรายใบ — เนื้อการ์ด v2: ผ่าตัด 11 · เปลี่ยนชื่อ 5 · ใหม่ 3 (3 ก.ย. 69)

> ผู้เขียน: มือเขียนหลัก (Fable-max) สาย cards ตามแบบ `NEWS-CARD-LIBRARY-DESIGN-FINAL-3sep69.md` (F4+F5+F8)
> ของจริงอยู่ที่ `data/card-library-v2/plan-cards.json` — เอกสารนี้คือคู่มือผู้ตรวจไขว้ (เกณฑ์ S1: อ่าน "ชื่อ+600 ตัวแรก" รายใบ)
> สถานะ: ร่างเสนอ ยังไม่แตะ store/DB — จะมีผลครั้งแรกในไฟล์คลังแขนแล็บ (B/C) เท่านั้น

## 0) หลักที่ใช้ทุกใบ ("การ์ดผอม" ของแบบสุดท้าย §2)

1. **600 ตัวแรก = ของ luna**: ใบผ่าตัด/เปลี่ยนชื่อ 16 ใบ — ประโยค 1–2 คือ scenario ที่การ์ดเก่งสุด + เดิมพันของเรื่อง แล้วตามด้วยบรรทัด `ใช้เมื่อ:` ตรงๆ (ตรวจนับแล้ว "ใช้เมื่อ:" เริ่มภายในตัวอักษรที่ 159–250 ทุกใบ) · **ใบใหม่ 3 ใบ (รอบแก้ตามผู้ตรวจ): สลับให้ `ใช้เมื่อ:` เป็นบรรทัดแรกตามตัวอักษร F8 ของแบบ** แล้ว scenario+เดิมพันตามเป็นบรรทัด 2 — ทั้งสองท่อนจบภายใน 600 ตัวแรกเช่นเดิม
2. **การ์ดเลิกสอนฝีมือกลาง**: ไม่มีคำสั่งปิดเรื่อง/อวยพร/คำคม ไม่มีเลขย่อหน้า ไม่มีสั่งความยาว ไม่มีแพตเทิร์นประโยคเปิดตายตัว และไม่มีชุดวลีให้ก๊อป (ต้นเหตุ "คนจับสูตรได้") — เปิด/ปิด/โครง/จุดหัก เป็นเสียงเดียวของ VR-001..010
3. **เนื้อที่การ์ดยังสอน** (สิ่งที่กฎกลางไม่รู้): ขอบเขตข้อเท็จจริงประจำหมวด ("ของที่ต้องหาจากต้นฉบับ") · ตัวเลขทองของหมวด (รับใช้ VR-003) · ภาพจำประจำหมวด (รับใช้ VR-005) · จุดยืนคนเล่าประจำหมวด 1 ประโยค พร้อมคำสั่ง "เขียนใหม่ทุกครั้ง" (รับใช้ VR-007 โดยไม่สร้างสูตรใหม่) · กติกาตัวเอกเป็นคนไม่ใช่องค์กร (รับใช้ VR-002)
4. **doNot ครบ 3 แกนทุกใบ**: ห้ามแต่ง (รวมท่าทาง/การปฏิเสธ) · ห้ามเดาเพศ-บทบาท · ห้ามประโยคน้ำ + ข้อเดิมที่ดี (ชี้นำ/เหน็บ/กระชาก/ภาษาทางการ/CTA) — ตัดท่อน "จบที่ใจความหรืออวยพรสั้นๆ" ที่ชน VR-006 ออกจากทุกใบ
5. **ตรวจอัตโนมัติแล้ว**: JSON valid · id ตรง store 16/16 · replaceUntil เจอครั้งเดียวทุกใบ · คำต้องห้าม (อวยพร/คำคม/สัจธรรม/ปิดสั้น/1-2 ประโยค/ย่อหน้า/จบที่ใจความ/ความยาว/Native Thai Framework) = 0 ใน field ใหม่ทั้งหมด · ไม่มีประโยคยาวซ้ำข้ามใบ
